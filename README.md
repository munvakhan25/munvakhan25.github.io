
### 3D Personal Portfolio

**A digital space built to showcase ideas, experiments, and engineering.**

This portfolio is more than a collection of projects. It represents my journey as an AI & Data Science engineering student, my curiosity for technology, and my interest in building things that combine functionality with thoughtful design.

## ✦ The Experience

I wanted to create something different from the usual portfolio templates.

The result is a minimal, white neumorphic interface with a futuristic 3D centerpiece, subtle motion, layered surfaces, and a clean visual hierarchy.

Every element is designed to keep the experience immersive without making it complicated.

## ✦ What You'll Find

- **About:** My background, interests, and engineering journey.
- **Skills:** Technologies, programming languages, and tools I work with.
- **Experience:** Internship experiences and practical learning.
- **Projects:** Selected work, experiments, and GitHub repositories.
- **Education:** Academic background and certifications.
- **Contact:** Direct ways to connect with me.

## ✦ Built With

- HTML5
- CSS3
- JavaScript
- CSS 3D Transforms
- Responsive Web Design
- Google Fonts

No heavy frameworks. Just carefully structured frontend code.

## ✦ Design Philosophy

**Less noise. More intention.**

A combination of soft neumorphic surfaces, clean typography, subtle blue accents, and interactive depth creates the visual identity of this portfolio.
